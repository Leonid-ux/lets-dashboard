# Lets Dashboard

Lets Dashboard — приложение для симрейсеров, которое помогает следить за прогрессом в iRacing.

В приложении можно смотреть историю сессий, последние гонки, iRating, активность, статистику по трассам и машинам, а также прогресс, задания и достижения.

## Скачать

Готовый `.exe` доступен во вкладке **Releases** этого репозитория.

Скачайте установщик, запустите его и следуйте инструкциям установки.
