# Lets Dashboard

Lets Dashboard — приложение для iRacing, оверлей, дашборд, поддержка симеджик подсветки, а так же хаптиков симпсоннов .


## Скачать

Готовый `.exe` доступен во вкладке **Releases** этого репозитория.

Скачайте установщик, запустите его и следуйте инструкциям установки.
